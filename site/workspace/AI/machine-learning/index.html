    机器学习

    机器学习的研究目标 ：利用经验改善系统自身的性能

    训练的根本目标： 获得泛化能力（应对未来未见测试样本的能力）

    基本术语

    • 输出空间 == 标记空间
    • 机器学习的任务分类方法
    • 基本假设：独立同分布
    • 名词解释：
      • 假设空间：所有可能性的集合
      • 版本空间：所有与样本符合的假设的集合
      • 归纳偏好

    模型评估与选择

    • 训练误差与泛化误差、测试误差的关系

    • 过拟合、欠拟合

    • 训练误差分类和问题分类

    评估方法

    每个方法计算错误率

    • 留出法（hold-out）： 分出两个集合

    • 交叉验证法（cross-validation）：k划分，取一作为测试

      • 特例：留一法

    • 自助法（bootstrapping）: 随机采样m个

    • 验证集和测试集

    性能度量（performance measure）

    • 各类任务的常用度量方法

    • 错误率，精度、查全率、查准率、精确度、准确度、召回率、

    • P-R 曲线和平衡点
    • F1-score计算 和 \(\beta\)变体 、宏变体 和 微变体
    真实情况\预测结果 正例 反例
    正例 TP（真正例） FN（假反例）
    反例 FP（假正例） TN（真正例）
    • 真正例率和假正例率：各自有多少预测对 ROC曲线的定义和构建 和 AUC值

    AUC值：ROC曲线下的面积 | 衡量了样本预测的排序质量

    • 需要每个样本有值预测，并正反例，逐个设置阈值

    代价敏感错误率：非均等的代价求和平均

    • 为错误赋予非均等代价
    • 代价矩阵:\(cost_{ij}\)表示将第\(i\)类预测为第\(j\)类的代价.
    • 二分类任务为例
    真实\预测 第 0 类 第 1 类
    第0类 0 \(cost_{01}\)
    第1类 \(cost_{10}\) 0
    • 非均等代价下，ROC曲线无法直接反映出学习器的期望总体代价，但是“代价曲线（cost curve）”可以.
    • 横轴为正例概率代价\(P(+)cost = \frac{p \times cost_{01} }{p \times cost_{01} + (1-p) \times cost_{10} }\), 其中\(p\)是样例为正例的概率
    • 纵轴为归一化代价\(cost_{norm} = \frac{FNR \times p \ times cost_{01} + FPR \times (1-p) \times cost_{10} }{p \times cost_{01} + (1-p) \times cost_{10} }\) 其中\(FNR = 1- TPR\)是假反例率
    • ROC曲线上每个点，都对应代价平面上一条线段，取所有线段的下界，围成的面积为在所有条件下学习器的期望总体代价

    比较检验： 估计泛化性能

    性能比较：测试性能不等于泛化性能，测试性能随测试集变化，机器学习算法本身具有随机性

    统计假设检验（hypothesis test）为学习器性能比较提供了重要依据：

    • 基于假设检验结果，我们可以推断，若在测试集上观察到学习器A比B好，则A的泛化性能是否在统计意义上优于B，以及这个结论的把握有多大。

    假设检验：

    泛化错误率为\(\epsilon\)的学习器被测得测试错误率为\(\hat{\epsilon}\)的概率：

    \[P(\hat{\epsilon};\epsilon) = \binom{m}{\hat{\epsilon} \times m} \epsilon^{\hat{\epsilon} \times m}(1-\epsilon)^{m-\hat{\epsilon}\times m}\]
    • 对\(\epsilon\)求偏导可知，当\(\epsilon = \hat{\epsilon}\)时，概率最大，符合二项分布

    二项检验：置信度

    • 简单解释：在假设为真的前提下的到观测结果的概率与我们愿意冒的风险做比较，来确定假设的置信度

    • 考虑假设\(\epsilon \leq \epsilon_0\),则在\(1-\alpha\)的概率内所用观测到的最大错误率如下式计算：

    \[\bar{\epsilon} = max \epsilon \quad s.t. \sum^{m}_{i=\epsilon_0 \times m + 1} \binom{m}{i}(1-\epsilon)^{m-i} < \alpha\]

    • 假若测试错误率\(\hat{\epsilon}\)小于临界值\(\bar{\epsilon}\)，则根据二项检验可以得出结论：在\(\alpha\)的显著度下，假设\(\epsilon \leq \epsilon_0\)不能被拒绝.

    • 很多时候我们会做多次训练和训练，得到多个测试错误率，此时可以使用t-检验(t-test)（P40）

    • 进一步有交叉验证t-检验（P41）、McNemar检验、Firedman检验与Nemenyi后续检验

    线性判别分析(Linear Discriminant Analysis, LDA)

    给定已分类好的数据，希望找到区分这些类别的特征. 降维只是副产物，既然 有了区分它们的特征，就能够决定保留哪些主要特征。

    使用概念: - 类内散度矩阵、类间散度矩阵、广义瑞利商 - 求解使用奇异值分解

    局限性：

    • 默认每个类别的数据都遵循正态分布，且数据分布形状差不多.
    • 对小样本，高维数据脆弱
    • 矩阵信息来源于 \(C\) 个类别中心，因此最多只能捕捉\(C-1\)个差异方向.
    • 只能发现线性差异。

    决策树 CART（Classification And Regression Tree）

    解决什么问题：基于哪些特征，以及如何根据这些特征的取值，来对目标变量做出一系列判断

    本质概括： 决策树是根据样本数据的分布情况，使用信息熵或是纯度度量来确定分支条件和样本集划分，最终依据最终样本集中的数据真值情况做出预测，分类树是真值的类别众数，回归树则是平均值

    关键点：1. 决策树是数据驱动的，树的结构完全取决于数据分布。 2. 预测值完全来源于训练样本，因此决策树不能外推

    核心逻辑链：

    • 输入：带有标签的训练样本集（分类树标签是类别，回归树标签是数值）。
    • 构建过程（训练）：
    • 在每个节点，根据样本数据的分布情况（分类树看类别比例，回归树看数值离散程度）。
    • 使用纯度度量指标（分类树用信息熵/基尼系数，回归树用均方误差MSE）。
    • 选择能最大程度提升纯度的特征和分裂阈值，确定分支条件。
    • 递归划分样本集，直到满足停止条件。
    • 叶子节点存储：
    • 不再划分的叶子节点，依据该节点内样本的真实标签做出预测准备。
    • 分类树：存储类别众数（出现最多的那个类别）。
    • 回归树：存储数值平均值。
    • 预测（推理）：新样本顺着树走到叶子节点，直接输出该节点预先存好的众数或平均值。

    分类任务

    聚类

    以自定义的特征和距离度量标准，去发现样本中的类别关系.

    关键概念

    • 距离度量 和 相似度度量
    • 外部指标 和 内部指标

    原型聚类

    • k 均值散发： k个类别算最小平分误差
    • 学习向量量化： 学习原型向量
    • 高斯混合聚类：使用概率模型
    • 密度聚类：密度直达、密度可达、密度相连
    • 层次聚类：不断合并，最近的

    降维与度量学习

    • k近邻学习(k-Nearest Neighbor, kNN)

    低维嵌入

    基于假设：与学习任务密切相关的可能仅是某个低维分布，即高维空间中的一个低维“嵌入”

    “多维缩放”（Multiple Dimensional Scaling, MDS）

    • 要求：原始空间中样本之间的距离在低维空间中得以保持
    • 过程：需要中心化，由不变的距离矩阵求取降维后的内积矩阵\(\textbf{B}\),对内积矩阵做特征值分解
    • 目标：求得每个样本的低维坐标

    拓展到普遍的线性变换的线性降维方法

    主成分分析（Principal Component Analysis, PCA）

    PCA不关心后续任务，唯一目标时，找到一个低维表示，并尽可能地保留原始数据中的信息，即包含信息量最大，使样本呈现最大差异的维度.

    看待问题的两面

    • 最近重构性：样本点到这个超平面的距离都足够近
    • 最大可分性：样本点在这个超平面上的投影能尽可能分开（方差尽可能大）

    其等价性来源于数据的空间总方差守恒，在一个维度上方差越大，在其正交维度上方差越小.

    过程

    • 中心化
    • 计算样本的协方差矩阵
    • 特征值分解
    • 选取特征向量

    局限性

    • 只能发现数据中的线性结构，无法处理非线性关系.
    • 对尺度敏感（需要标准化）
    • 无法处理缺失值
    • 对异常值敏感
    • 可解释性下降(因为保留的特征变为了原始特征的线性组合)
    • 无法处理类别特征
    • 启发式特征选择

    核化线性降维

    极度依赖自动化函数和参数探索，特定性使用，不适用于泛化性问题。

    • 将“原本采样的”低维空间称为 “本真”（intrinsic）低维空间

    核主成分分析（Kernelized PCA, KPCA）

    通过核函数，利用高维信息进行降维

    它的计算开销较大。

    流形学习（manifold laerning）

    • 着眼于局部性质

    "流形" 是在局部与欧氏空间同胚的空间.

    等度量映射（Isometric Mapping， Isomap）

    • “测地线”（geodesic）距离，沿曲面的最近距离

    • 计算近邻连接图上的最短距离,可以采用Dijkstra算法或Floyd算法.得到任意两点的而距离后，可以通过MDS方法来获得坐标.

    想要进一步得到映射，目前只能通过训练一个回归学习器来进行预测.

    • 近邻图的构建(均有不足):数目阈值、距离阈值

    局部线性嵌入(Locally Linear Embedding, LLE)

    • 试图保持邻域内样本之间的线性关系

    对\(\mathbf{M} = (\mathbf{I} - \mathbf{W})^{\mathbf{T}} (\mathbf{I} - \mathbf{W})\)进行特征值分解，取特征向量得到矩阵\(\mathbf{Z}^{\mathbf{T}}\)

    度量学习(metric learning)

    直接学习一个合适的距离度量

    马氏距离(Mahalanobis distance)：对每个维度的距离施加不同权重

    可对近邻分类器做距离概率的拓展

    即求解\(\underset{\mathbf{P}}{min} \; 1 - \overset{m}{\underset{i=1}{\sum}}\underset{j \in \Omega_i}{\sum} \frac{exp(-\|\mathbf{P}^{\mathbf{T}}x_i - \mathbf{P}^{\mathbf{T}}x_j\|^2_2)}{\sum_l exp(-\|\mathbf{P}^{\mathbf{T}}x_i - \mathbf{P}^{\mathbf{T}}x_l\|^2_2)}\)

    特征选择与稀疏学习

    目的： 选择相关特征，去除无关特征和冗余特征（可被其它特征计算得出）

    子集搜索：贪心或穷举 子集评价：以子集A划分数据集的信息熵增益

    特征选择方法分类

    过滤式选择（filter）

    先对数据集进行特征选择，再训练学习器，特征选择过程与后续学习器无关.

    Relief(Relevant Features)方法

    设计了一个“相关统计量”来度量特征的重要性

    • 统计量是一个分量，每个分量对应于一个初始特征。
    • 特征子集的重要性由子集中每个特征所对应的特征统计量分量之和决定.

    定义 猜中近邻 与 猜错近邻， 相关统计量对应于属性 \(j\) 的分量为：

    \[\delta^j = \underset{i}{\sum}-diff(x_i^j, x_{i,nh}^j)^2 + diff(x_i^j,x_{inm}^j)^2,\]

    Relif 是为二分类问题设计的，拓展变体 Relief-F能处理多分类问题.

    包裹式选择

    将最终要使用的学习器的性能作为特征子集的评价准则.

    LVW (Las Vegas Wrapper)方法，在拉斯维加斯方法(Las Vegas method)框架下使用随机测量进行子集搜索，再使用交叉验证法估计学习器误差.

    由于随即策略，和每次都要训练学习器的原因，这个方法的计算开销很大. 在有运行时间限制的情况下，可能给不出解.

    嵌入式选择

    将特征选择放在训练过程中完成.

    岭回归(ridge regression):引入惩罚项\(\lambda \|w\|^2_2\)，防止过大的系数.

    若采用L1范数，则称其为LASSO(Least Absolute Shrinkage and Selection Operator)
