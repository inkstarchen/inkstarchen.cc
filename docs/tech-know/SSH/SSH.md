- 什么是SSH
	- Secure Shell 的缩写， 安全外壳协议。是一种网络协议，SSH-2有多种实现
	- 用于在不安全的网络中安全地远程登陆和执行命令
- 为什么需要SSH？
	- 历史上，网络主机之间的通信是不加密的，属于明文通信。并不安全，登录远程服务器时输入的密码时能够被线路所经过的中间计算机所获取。
	- SSH能够加密计算机之间的通信，保证不被窃听或篡改。

- SSH架构是服务器-客户端模式（Server - Client）


- SSH如何工作？
	- 建立安全连接
		- 客户端和服务器进行握手？
		- 使用非对称加密算法，完成密匙交换，协商出一个会话密钥
		- 以后的通信都是用对称加密数据
	- 身份验证
		- 口令认证：用户输入密码
		- 公钥认证：
			- 用户在本地生成一对密钥对（私钥+公钥）
			- 公钥放在服务器上
			- 登陆时服务器发一个挑战（随机数），要求客户端用私钥签名
			- 服务器用公钥验证签名
	- 加密传输
