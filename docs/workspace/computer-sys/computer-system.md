## 总论

> 我们需要一层一层的抽象，假定底层的运行是正确无误的，从而在上层考虑它应该考虑的问题。

### 操作系统提供的主要服务

- 进程管理
- 内存管理
- 存储管理
- IO设备管理
- 保护和安全

#### 进程管理
- 创建和删除进程
- 挂起和恢复进程
- 提供进程并发同步的方法
- 提供进程间通信的方法
- 提供解决死锁的方案

#### 内存管理

追踪内存中哪些部分正在被哪些进程使用

- 决定哪些进程和数据要移入内存或从内存移出
- 根据需要分配和释放内存空间

#### 存储管理
操作系统运行文件系统管理

- 创建和删除文件和目录
- 操作文件和目录
- 将文件映射到二级存储
- 在稳定存储介质上备份文件
- 空余空间股那里
- 存储空间分配
- 磁盘调度

#### IO设备管理
- 缓冲传入的数据
- 输出数据

#### 保护和安全

保护：进程的资源访问控制策略

安全：防止外部和内部攻击

- 内存保护，设别保护
- 进程和文件的权限控制


- 受保护的指令（只有操作系统能够执行）
	- I/O设备的直接访问
	- 管理内存管理的状态
	- 支持halt指令叫停处理器

RISCV 的模式

| Level | Encoding | Name             | Abbreviation |
| ----- | -------- | ---------------- | ------------ |
| 0     | 00       | User/Application | U            |
| 1     | 01       | Supervisor       | S            |
| 2     | 10       | Reserved         |              |
| 3     | 11       | Machine          | M            |

当操作系统挂载完毕，所有进入内核的操作都以事件出现

- 中断由外部事件引起：如硬件
- 异常由指令执行引起：如软件引起的中断

**Trap**
- 用户态与内核态的切换的中介
