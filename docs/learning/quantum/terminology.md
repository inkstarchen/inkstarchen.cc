| 量子力学术语                         | 线性代数术语                     |
| ------------------------------ | -------------------------- |
| 态矢量（State Vector）              | 向量（Vector）                 |
| 本征态（Eigenstate）                | 特征向量（Eigenvector）          |
| 本征值（Eigenvalue）                | 特征值（Eigenvalue）            |
| 右矢（ket）$\vert a\rangle$        | 列向量                        |
| 左矢（bra）$\langle a\vert$        | 行向量                        |
| $\langle a \mid b \rangle$     | a 和 b 向量的内积（Inner Product） |
| $\vert a\rangle\langle b\vert$ | a 和 b 的外积构成的投影矩阵           |

> $\vert a\rangle\langle a\vert$ 才是在 $a$ 方向的投影算子

| 量子力学术语 | 线性代数术语 |
|---|---|
| 基态 (Ground State) | 最小本征值对应的本征态 (Eigenstate with Lowest Eigenvalue) |
| 算符 (Operator) | 矩阵 (Matrix) |
| 线性算符 (Linear Operator) | 线性变换 (Linear Transformation) |
| **幺正（酉）算符 (Unitary Operator)** | **酉矩阵 (Unitary Matrix)** |
| **厄米算符 (Hermitian Operator)** | **厄米矩阵/自伴矩阵 (Hermitian/Self-adjoint Matrix)** |
| 线性叠加原理 (Principle of Superposition) | 线性组合性质 (Linearity) |
| 投影算符 (Projection Operator) | 投影矩阵 (Projection Matrix) |
