- 什么是**静态链接** ？

通过静态链接，可以生成一个可执行文件（完全链接或部分链接）。部分链接的可执行文件中的有些符号需要等到可执行文件加载时甚至是运行时才会进行符号解析和重定位。

两种连接方式都要进行符号解析和重定位两个任务。两者区别之一就是执行这两个任务的时机。动态链接分为加载时和运行时两种动态链接方式。
