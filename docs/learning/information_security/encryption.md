## 非对称加密算法

- 什么是对称加密？
	- 加密和解密使用同一套密钥
- 什么是密钥？
	- 在加密解密过程中所需要的关键信息，控制加密解密的结果
	- 以AES算法为例子

## AES算法

- 什么是AES算法？
	- AES是Advanced Encryption Standard的简称，高级加密标准，是一种对称加密算法标准
- AES算法怎么实现？
	- 以AES-128为例，密钥是128位的二进制序列
	- 思想：一轮一轮打乱 + 混合数据
	- 加密过程
		- 密钥扩展（Key Expansion）：把最初的128位密钥，用一个确定算法拓展成11个子密钥（Round Keys）每个128位
		- 初始轮 AddRoundKey：明文块（128位）和第一个子密钥做XOR
		- 中间九轮（每轮4步）
			- SubBytes：字节替换（查S盒，非线性混淆）？
			- ShiftRows：行位移（打乱字节位置）
			- MixColumns：列混合（数学矩阵运算，进一步扩散）
			- AddRoundKey：再将本轮子密钥XOR进去
		- 最后一轮（略去MixColumns）
			- 得到密文块
	- 解密过程：
		- 加密反操作
`2b 7e 15 16 28 ae d2 a6 ab f7 97 75 46 20 63 18`
- 怎么做算法扩展？
	- 核心操作
		- RotWord：将四字节循环左移一个字节`[a0, a1, a2, a3] → [a1, a2, a3, a0]`
		- SubWord：将四字节中每个字节通过AES S-box替换
		- Rcon\[1\]：轮常数，保证每轮密钥不重复，通过GF(2^8)下$RC_1 = 0x01,\quad RC_i = 2 \cdot RC_{i-1}$计算得到
		- `W[i] = W[i-4] ⊕ SubWord(RotWord(W[i-1])) ⊕ Rcon[i/4]`
		- `W[i] = W[i-4] ⊕ W[i-1]`
- 什么是 AES S-box（Substitution box）？
	- 对数据进行非线性变换的查找表
	- 通过有限域GF(2^8)的数学方法生成
	- 步骤
		- 求逆元
			- 对每个非零字节b在GF(2^8)中求逆元$b^{-1}$
			- (0x00的逆元定义为自己)
		- 仿射变换（Affine Transformation)
			- 将求得的逆元做一个固定的线性变换加上常量向量）
			- $S(b)=A \cdot b^{-1} + c$
- 什么是GF(2^8)
	- GF = Galois Field，伽罗瓦域（有限域）
	- 形式:$GF(p^n)$
		- $p$是素数，表示域的底数（元素个数的质因数）
		- $n$是正整数，表示域的扩张次数
	- 支持运算（见加减乘除），域中共有$p^n$个元素
	- 加法=减法=异或
	- 除法= 乘以逆元
	- 乘法：$b=b_7x^7 + b_6 x^6 + \dots + b_0$,普通多项式乘法对2取模，再对$m(x)$取模
	- 求逆元？直接通过幂运算$b^{-1} = $算好，然后查表 或者使用扩展欧几里得算法
- 什么是扩展欧几里得算法？$s(x)⋅b(x)≡1(modm(x))$
	- 初始化$r0​=m(x),r1​=b(x)$,$s0​=1,s1​=0$,$t0​=0,t1​=1$
	- 循环计算$qi​=r_{i−1}​÷ri​(多项式除法，系数 mod 2)$
	- $r_{i+1}​=r_{i−1}​−qi​⋅ri​(系数 XOR)$
	- $s_{i+1}​=s_{i−1}​−qi​⋅si​$
	- $t_{i+1}​=t_{i−1}​−qi​⋅ti​$
	- 终止条件:$当 ri+1=0r_{i+1} = 0ri+1​=0 时，ri=gcd⁡(b(x),m(x))=1r_i = \gcd(b(x), m(x)) = 1ri​=gcd(b(x),m(x))=1$
- 什么是$m(x)$？
	- 固定不可约多项式$m(x) = x^8 + x^4 + x^3 + x + 1$
	- 理论上可以有不同的，但是这是测试出的优势多项式
