# 抽象部分
## 二元关系
- **反身：**$aRa$
- **对称：** $aRb，bRa$
- **反对称：**$aRb,bRa=>a=b$
- **传递：** $aRb,bRc=>aRc$

等价关系：自反，对称，传递->等价类（元素集合）

$$线性空间->域->交换环->交换群->群$$
$$<G:o>群：（1）结合律（2）单位元（3）逆元$$$$(1)->半群，（1）（2）->含幺半群$$$$群+交换律->交换群（Abel群）$$
$$<G:+,o>环：（1）交换群（+），单位元记作0$$$$（2）<R:0>为半群（3）o对+满足分配律$$
$$o满足交换律->交换环，存在单位元=>含幺环$$
