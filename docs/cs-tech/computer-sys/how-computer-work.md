电脑开机后，CPU执行BIOS程序

CPU上电后， 指令指针（IP/RIP）寄存器被硬件设置为一个固定的地址。

- 什么是BIOS？
	- Basic Input/Output System(基本输入输出系统)
	- 固件程序，存放在主板上的 ROM/Flash 芯片中
- BIOS主要功能
	- 硬件自检
	- 初始化硬件
	- 查找启动设备并加载Bootloader
- 它怎么检测到Bootloader？Bootloader有标识符吗？
- UEFI系统（区别于传统BIOS系统）
	- Bootloader存放在EFI系统分区（ESP）
	- 以标准文件格式存在(如`bootx64.efi`)
	- UEFI固件通过文件系统和启动项配置表找到可执行文件
- 什么是UEFI？
	- Unified Extensible Firmware Interface（统一可扩展固件接口）
	- 主板固件程序，类似BIOS，但更现代化、功能更强大。
